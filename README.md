 Hospital Patient Data Analysis – Excel Dashboard

📌 Project Overview

This project focuses on analyzing hospital patient records using Microsoft Excel to understand hospital performance, patient admissions, 
treatment status, discharge patterns and insurance coverage.

The dashboard transforms raw patient data into meaningful business insights using KPI cards, charts, Pivot Tables and interactive filters.

The main objective is to monitor hospital activities, understand patient demographics and support better healthcare management decisions.

🎯 Project Objectives

- Analyze total patient admissions.
- Calculate average length of hospital stay.
- Analyze insured and uninsured patients.
- Monitor discharged patients.
- Track patients under treatment.
- Analyze gender-wise patient distribution.
- Identify the most common diagnoses.
- Analyze city-wise patient distribution.
- Understand admission patterns.
- Generate meaningful hospital business insights.

🛠️ Tools and Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Conditional Formatting
- Data Cleaning
- Data Analysis
